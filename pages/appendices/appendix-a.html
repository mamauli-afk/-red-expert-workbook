Red Expert

GUI-инструмент для администрирования и разработки баз данных Firebird (а также других СУБД): подключение, редактор схем, SQL-редактор, создание БД и объектов.

↑ к оглавлению

Firebird

Реляционная СУБД с открытым исходным кодом. Поддерживает SQL-диалект 3, хранимые процедуры, триггеры, генераторы (sequences). База данных хранится в одном файле .fdb.

↑ к оглавлению

.fdb

Расширение файла базы данных Firebird. Файл размещается на сервере Firebird; приложение подключается к нему по сети (порт 3050) или локально через embedded-режим.

↑ к оглавлению

SYSDBA

Встроенная учётная запись администратора Firebird с максимальными правами. Пароль по умолчанию в учебных установках — masterkey; в реальных проектах его обязательно меняют.

↑ к оглавлению

FbConnection

Класс ADO.NET-драйвера FirebirdSql.Data.FirebirdClient для установления соединения с Firebird. Аналог SqlConnection / NpgsqlConnection.

↑ к оглавлению

Avalonia UI

Кроссплатформенный UI-фреймворк для .NET с поддержкой XAML.

↑ к оглавлению

MVVM

Паттерн Model-View-ViewModel, разделяющий логику и представление.

DataGrid

Элемент управления для отображения табличных данных.

↑ к оглавлению

EF Core

ORM от Microsoft для работы с БД через объекты C#. Для Firebird используется провайдер FirebirdSql.EntityFrameworkCore.Firebird.

↑ к оглавлению

CRUD

Create, Read, Update, Delete — базовые операции над данными.

↑ к оглавлению

IPrintService

Интерфейс Avalonia для интеграции с системной печатью.

↑ к оглавлению

Scaffolding

Автоматическая генерация классов сущностей и DbContext по существующей схеме БД (команда dotnet ef dbcontext scaffold с указанием провайдера Firebird).

↑ к оглавлению

Connection String

Строка подключения — набор параметров (DataSource, Port, Database, Username, Password, Charset), используемый для соединения с Firebird.
