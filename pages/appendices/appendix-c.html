Пошаговая настройка

  1. Установить .NET SDK (версия 8.0 или новее).
  2. Установить VS Code и расширения: C# Dev Kit, Avalonia for VS Code, Live Server.
  3. Установить Firebird Server (порт 3050) и клиентскую библиотеку fbclient.dll.
  4. Установить Red Expert и подключиться к Firebird (DataSource, порт 3050, SYSDBA / masterkey).
  5. Установить шаблоны Avalonia: dotnet new install Avalonia.Templates.
  6. Создать проект с архитектурой MVVM: dotnet new avalonia.mvvm -o MyApp.
  7. Добавить NuGet-пакеты: FirebirdSql.EntityFrameworkCore.Firebird, FirebirdSql.Data.FirebirdClient, Microsoft.EntityFrameworkCore.Design.
  8. Открыть проект в VS Code: code MyApp.

Структура MVVM-проекта

После создания проекта по шаблону avalonia.mvvm, вы увидите следующие папки:

  • Models/ — классы данных (сюда мы потом поместим сгенерированные из БД модели).
  • ViewModels/ — логика окон и привязка данных (C#).
  • Views/ — визуальная часть окон (XAML-файлы).

Такое разделение позволит нам легко реализовать CRUD-операции в Модуле 3.
