Тема 3.1. Реализация окна авторизации

Теория

Окно авторизации (LoginWindow) должно перехватывать ввод логина и пароля. После нажатия кнопки «Войти» приложение отправляет запрос к таблице пользователей в БД Firebird. Если учетные данные совпадают, открывается главное окно, иначе выводится сообщение об ошибке.

Тема 3.2. Построение главного окна с DataGrid

Теория

Для отображения табличных данных в Avalonia используется элемент DataGrid. Согласно паттерну MVVM (Model-View-ViewModel), данные привязываются к свойству ObservableCollection во ViewModel. Это позволяет таблице автоматически обновляться при добавлении или удалении записей.

Практическое задание

Напишите C# код ViewModel, который загружает список сотрудников из БД и сохраняет его в ObservableCollection.

Тема 3.3. Реализация CRUD-операций

Теория

CRUD (Create, Read, Update, Delete) — базовые операции. В Avalonia UI действия пользователя (нажатие кнопок) привязываются к командам (ICommand) во ViewModel. При добавлении или удалении объекта в контексте EF Core необходимо вызвать метод SaveChangesAsync(), чтобы отправить изменения в Firebird.
