Цель модуля

Освоить визуальное проектирование и создание базы данных Firebird с помощью GUI-инструмента Red Expert.

Теория и практика

Тема 1.1. Введение в Red Expert

Теория

Red Expert — это бесплатный кроссплатформенный инструмент для администрирования и разработки баз данных, отлично поддерживающий Firebird. Интерфейс состоит из панели инструментов, браузера баз данных (слева) и рабочей области. В браузере отображается структура подключенных БД: таблицы, представления, триггеры, генераторы и хранимые процедуры.

Практическое задание

Запустите Red Expert, создайте новое подключение и откройте браузер базы данных. Сделайте скриншот главного окна Red Expert и прикрепите его ниже.

Тема 1.2. Создание и настройка подключения

Теория

Для подключения к Firebird в Red Expert необходимо указать параметры сети и аутентификации. Стандартный порт Firebird — 3050. В качестве пути к базе данных указывается путь к файлу .fdb (например, localhost:C:\db\test.fdb). Учётная запись администратора по умолчанию — SYSDBA, пароль — masterkey.

Практическое задание

Создайте новое подключение к локальному серверу Firebird. Напишите в поле ниже строку подключения, которую вы использовали (или сформировали) для соединения.

Тема 1.3. Создание базы данных и таблиц

Теория

В отличие от клиент-серверных СУБД (как PostgreSQL), база данных Firebird — это физический файл с расширением .fdb. Вы можете создать его через Red Expert. Для создания таблиц используется визуальный редактор или SQL-скрипты. Первичные ключи (PK) и внешние ключи (FK) настраиваются для обеспечения целостности данных. Для автоинкремента в Firebird используются генераторы (sequences) и триггеры.

Практическое задание

Создайте файл базы данных employees.fdb и таблицу Departments (поля: ID (PK), Name). Напишите SQL-код (DDL), который вы использовали для создания таблицы.

Тема 1.4. Редактор запросов

Теория

Встроенный редактор запросов Red Expert позволяет выполнять SQL-скрипты (диалект 3), подсвечивает синтаксис и хранит историю выполненных операций. Результаты выборки (SELECT) можно экспортировать в CSV или Excel. Все изменения в БД (INSERT, UPDATE, DELETE) применяются после фиксации транзакции (Commit).

Практическое задание

Откройте редактор запросов. Напишите и выполните INSERT запрос, добавляющий запись в таблицу Departments. Напишите код, который вы выполнили.

Самопроверка

  • Скриншот интерфейса загружен
  • Строка подключения записана
  • SQL для создания таблицы написан
  • INSERT запрос выполнен
