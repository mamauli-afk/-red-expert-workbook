Цель модуля

Настроить взаимодействие десктопного приложения на Avalonia с базой данных Firebird.

Теория и практика

Тема 2.1. Подготовка проекта Avalonia (MVVM)

Теория

Для правильной работы с данными (привязка таблиц, обработка нажатий) мы будем использовать паттерн MVVM (Model-View-ViewModel). В Avalonia есть готовый шаблон проекта с уже настроенной структурой папок (Views, ViewModels, Models).

Для работы с Firebird в C# необходимо установить соответствующие NuGet-пакеты. Основной пакет EF Core провайдера — FirebirdSql.EntityFrameworkCore.Firebird. Для прямого подключения по ADO.NET используется FirebirdSql.Data.FirebirdClient. Для генерации кода из БД потребуется Microsoft.EntityFrameworkCore.Design.

Практическое задание

1. В терминале VS Code создайте проект с MVVM-структурой:
dotnet new avalonia.mvvm -o EmployeeApp

2. Перейдите в папку проекта и добавьте необходимые пакеты для работы с Firebird и EF Core.

Вставьте в поле ниже вывод терминала об успешном создании проекта или список добавленных пакетов из файла .csproj.

Тема 2.2. Настройка подключения к БД

Теория

Строка подключения (Connection String) в Firebird содержит хост, порт, путь к файлу БД и учетные данные. В коде C# для открытия соединения используется класс FbConnection. Важно обрабатывать исключения (try/catch) при подключении, так как сервер может быть недоступен или путь к файлу может быть указан неверно.

Практическое задание

Напишите фрагмент кода на C#, который создаёт подключение FbConnection с вашей строкой подключения и открывает его асинхронно.

Тема 2.3. Scaffolding моделей (Генерация кода)

Теория

Entity Framework Core позволяет автоматически генерировать классы C# (модели и DbContext) на основе уже существующей базы данных. Для этого используется команда dotnet ef dbcontext scaffold, в которой явно указывается строка подключения и провайдер FirebirdSql.EntityFrameworkCore.Firebird. Сгенерированные классы принято помещать в папку Models.

Практическое задание

Выполните команду scaffolding в терминале VS Code для вашей БД, указав папку вывода Models. Вставьте в поле ниже сгенерированный класс Department (или другой вашей таблицы).

Самопроверка

  • MVVM-проект создан, пакеты установлены
  • Код подключения написан
  • Модели сгенерированы
