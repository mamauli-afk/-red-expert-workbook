Инструкция по работе с тетрадью

Прочитайте этот раздел перед началом работы. Здесь описано, как устроена электронная рабочая тетрадь, из каких модулей она состоит, как сохранять ответы и как сформировать итоговый отчёт для проверки.

1. Общая характеристика

  • Целевая аудитория: студенты IT-направлений, изучающие разработку десктопных приложений на C# (Avalonia) и работу с базами данных (Firebird).
  • Формат: электронная тетрадь с полями для ответов, вставки скриншотов и автосохранением.
  • Стек технологий: Red Expert, Firebird, C#, Avalonia UI, Entity Framework Core.
  • Ключевой принцип: не менее 50–60% времени отводится на практическую работу непосредственно в VS Code и Red Expert.

2. Структура и содержание модулей

Тетрадь состоит из четырёх основных модулей, контрольного модуля и вспомогательных приложений:

Модуль 1. Проектирование базы данных в Red Expert

Цель: Освоить визуальное проектирование и создание схемы БД Firebird.

Темы: Интерфейс Red Expert, создание подключения и файла БД, создание таблиц (PK, FK), редактор запросов.

Практика: Создание схемы БД «Учёт сотрудников» (таблицы Employees, Departments, Positions).

Модуль 2. Интеграция Avalonia UI с Firebird

Цель: Настроить взаимодействие приложения Avalonia с БД.

Темы: Подготовка MVVM-проекта в VS Code, установка NuGet-пакетов Firebird, настройка строки подключения, Scaffolding (генерация моделей).

Практика: Подключение к БД и генерация моделей Employee, Department, Position.

Модуль 3. Авторизация и работа с данными на форме

Цель: Реализовать окно входа и интерфейс для просмотра/редактирования данных.

Темы: Создание LoginWindow, вывод данных в DataGrid (MVVM), реализация CRUD-операций (добавление, удаление, сохранение).

Практика: Создание окна авторизации и главного окна с таблицей сотрудников.

Модуль 4. Печать отчётов и экспорт данных

Цель: Научиться формировать и выводить на печать отчёты.

Темы: Обзор библиотек (IPrintService, FastReport), формирование макета отчёта, вызов системного диалога печати.

Практика: Генерация PDF-отчёта «Список сотрудников» и его печать.

Контрольный модуль (Экзаменующий)

Цель: Проверка и закрепление полученных знаний.

Содержание: Итоговый тест (15 вопросов) по всем темам, а также комплексное задание — разработка мини-приложения «Телефонный справочник» с нуля.

Приложения (А–Е): Глоссарий, справочник по SQL и C#, инструкция по настройке окружения, примеры кода, литература и критерии оценивания.

3. Требования к рабочему месту

Программное обеспечение:

  • Red Expert и сервер Firebird (порт 3050).
  • VS Code с расширениями: C# Dev Kit, Avalonia for VS Code.
  • .NET SDK (версия 8.0 или новее).
  • Браузер с поддержкой localStorage (Chrome, Edge, Firefox, Яндекс).

Важно! Все задания выполняются в одном браузере. Очистка кэша или режим инкогнито приведут к потере сохранённых ответов.

4. Как выполнять задания

  1. Переходите последовательно от Модуля 1 к Модулю 4.
  2. Перед заданием прочитайте блок «Теория», чтобы освежить знания.
  3. Выполните действие в Red Expert или VS Code.
  4. Запишите ответ в поле (текст, SQL-запрос, код C# или описание).
  5. При необходимости прикрепите скриншот результата.
  6. Поставьте галочку в чек-листе «Самопроверка» — прогресс обновится автоматически.

5. Как прикреплять скриншоты

  1. Сделайте скриншот (Win+Shift+S).
  2. Сохраните файл в формате PNG или JPG.
  3. В задании нажмите «Выбрать скриншот» и укажите файл.
  4. Убедитесь, что картинка появилась под кнопкой.

Ограничение: размер файла — не более 250 КБ. Именуйте файлы по схеме m1_t1.png (модуль_тема).

6. Сохранение ответов и экспорт отчёта

Тетрадь сохраняет текст и скриншоты автоматически в вашем браузере. Однако внизу каждой страницы есть панель кнопок:

  • Сохранить: фиксирует текущие данные.
  • Печать / PDF: открывает диалог печати. Выберите «Сохранить как PDF», чтобы получить итоговый отчёт для отправки преподавателю. При печати меню и кнопки скрываются.
  • Экспорт JSON: скачивает файл с вашими ответами (без скриншотов) в качестве резервной копии.
  • Сбросить данные: полностью очищает ответы на текущей странице (используйте с осторожностью!).

7. Правила оформления ответов

  • Текстовые ответы пишите кратко и по существу.
  • Ключевые слова SQL (SELECT, CREATE, INSERT) пишите заглавными буквами с отступами.
  • Код C# должен быть читаемым, с соблюдением отступов.
  • Скриншоты должны подтверждать выполнение задания.

Пример оформления SQL-ответа:

SELECT
    e.ID,
    e.FullName,
    d.Name AS DepartmentName
FROM Employees e
JOIN Departments d ON e.DepartmentID = d.ID
ORDER BY e.FullName;
