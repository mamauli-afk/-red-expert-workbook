Цель модуля

Научиться формировать и выводить на печать отчёты на основе данных из приложения.

Теория и практика

Тема 4.1. Обзор библиотек для генерации отчётов

Теория

В Avalonia UI можно использовать встроенный интерфейс IPrintService для вывода визуальных элементов на печать, либо сторонние библиотеки (например, FastReport.Avalonia, QuestPDF) для генерации PDF-документов. Для сложных табличных отчётов чаще выбирают генерацию PDF с последующей отправкой на печать.

Практическое задание

Какой подход к генерации отчётов вы выбрали для своего проекта и почему? Опишите ваш выбор.

Тема 4.2. Формирование отчёта

Теория

Процесс формирования отчёта включает выборку данных из Firebird (например, список сотрудников по отделам) и их компоновку в макет документа. Если вы используете PDF-генератор, вы описываете структуру таблицы, заголовки и стили в коде, после чего на выходе получаете готовый файл.

Практическое задание

Сгенерируйте тестовый PDF-отчёт со списком сотрудников. Загрузите скриншот полученного документа или напишите код, который вы использовали для его создания.

Файл не выбран

Тема 4.3. Вывод на печать

Теория

Для вывода на печать в Avalonia используется сервис IPrintService. Метод PrintAsync() открывает системный диалог печати, позволяя пользователю выбрать принтер. Если вы печатаете PDF, можно использовать системные вызовы ОС для открытия файла в программе просмотра.

Практическое задание

Напишите код, который вызывает диалог печати (или открывает PDF-файл) по нажатию на кнопку.

Самопроверка

  • Выбор библиотеки обоснован
  • Код отчёта написан
  • Скриншот отчёта загружен
  • Код печати написан
